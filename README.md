# ひと押し質問 / One-Tap Ask

よくある質問を、AIにひと押しで。Send ready-made questions to your AI in one tap.

A library of carefully written prompt templates (train trips with car/exit numbers, job legitimacy checks,
store vs online prices, fact-checks, letters, translations, recipes and more). Fill 1–3 boxes, then send
to Grok, ChatGPT or Perplexity (prefilled via `?q=`), Claude or Gemini (copied, then paste), or any app via Share.
Make your own templates with `{field}` placeholders; export/import JSON.

Free, no ads, no login. Prompts build offline; data stays on the device (IndexedDB).
Part of https://gutsmcd-cmd.github.io/free-apps/
